Inventory Mod for Left 4 Dead 2
================================

Start and play
  Add -insecure to Left 4 Dead 2's Steam launch options. Start the game,
  then run injector.exe. You can also run injector.exe start-client to start
  the game and load the mod in one step.

  Start a map yourself or join a private server running Inventory Mod.
  The server owns your inventory. It saves local games beside the DLL and
  keeps separate player saves on dedicated servers.

  Full releases include an addons folder. Keep it with the DLL. It supplies
  the Options > Inventory Mod page and the ammo pack models. Each player
  needs the ammo pack VPK to see the custom models.

Default controls
  I                 Open or close the inventory
  Middle mouse      Hold to open the wheel. Release or click to equip.
                    Right click to drop. Hold right click to drop all rounds
                    of the selected type.
  3–9, 0            Equip inventory slots 1–8
  Mouse wheel, [ ]  Cycle inventory selection
  ;                 Store the item or weapon in your hands
  H                 Store a nearby item or weapon in your sights
  U                 Unload the rounds from a supported gun
  V                 Mark a location, item or enemy when pings are enabled
  G                 Drop the item in your hands or the selected stored item
  E                 Use the game's pickup. The mod can store it when the
                    corresponding equipment slot is occupied.
  R                 Reload, or refuel a chainsaw when fuel is enabled
  Ctrl+End          Unload the mod

  Click an inventory box to select it, double-click to equip it, or drag
  it to move it. Right-click for Use, Drop one, or Drop all. The Items tab
  also offers magazine-size and full reserve drops.

Rules and settings
  Copy inventory_mod.example.toml to inventory_mod.toml beside the DLL to
  customize the inventory, weight, rounds, pings, chapter mutators,
  stamina, infection, melee, self-revive and chainsaw fuel for your game.
  The example describes the options. Edit inventory_mod_settings.toml
  with the game closed to change your own keys and presentation settings,
  or use the in-game Options page when the menu add-on is installed.

  inventory_mod_screamer.jpg  The shipped image for the infection screamer
  inventory_mod.inventory     Your single-player and local host save
  inventory_mod.log           Startup and game binding log
  DEPENDENCIES-LICENSES.txt    Notices for the Rust dependencies

Windows dedicated server
  Run injector.exe start-server [map] [port] to stage and launch a local
  LAN server. Use L4D2_SERVER_DIR for a custom dedicated server location.
  To install it manually, place inventory_mod.dll and your configuration in
  left4dead2/addons/inventory_mod/ under the server's installation and run:

  srcds.exe -console -game left4dead2 -insecure +plugin_load addons/inventory_mod/inventory_mod +map c1m1_hotel
